# Cinnamon — 3DS CIAs

CIAs of the Cinnamon GameMaker runner for Nintendo 3DS, built from
[Project-Sunshine-Native/cinnamon](https://github.com/Project-Sunshine-Native/cinnamon)
(UNDERTALE-3DS / DELTARUNE-3DS branches) with devkitPro.

## Install (pick one)

- **FBI → Remote Install → Scan QR Code** using the QR codes on
  https://lucgei231.github.io/cinnamon-3ds-cias/
- Or download the `.cia` below and install via FBI from SD.

| Game | File | UniqueId |
|------|------|----------|
| UNDERTALE 3DS | [undertale-3ds.cia](undertale-3ds.cia) | `0x1929` |
| DELTARUNE 3DS | [deltarune-3ds.cia](deltarune-3ds.cia) | `0x192A` |

## Game data

The CIAs are the runner only. Preprocessed game assets (textures/audio/data)
go on the SD card at `sdmc:/3ds/cinnamon`. You must provide your own game files.
